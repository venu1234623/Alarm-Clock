# Alarm Clock

A desktop alarm clock application built using Python and Tkinter.

## Features
- Set alarm time (Hours, Minutes, Seconds)
- GUI-based interface
- Plays alarm sound when time is reached
- Multi-threaded execution

## Technologies Used
- Python
- Tkinter
- Threading
- Datetime

## How to Run

python alarm_clock.py
